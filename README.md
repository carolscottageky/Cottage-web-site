# Carol's Cottage — simple free website

This is a single-page static site designed for free hosting.

## Recommended hosting: GitHub Pages
1. Create a free GitHub account at https://github.com/
2. Create a new public repository named `carols-cottage`.
3. Upload `index.html` and the `images` folder.
4. In the repository, go to Settings → Pages.
5. Choose "Deploy from a branch", select `main` and `/root`, then Save.
6. GitHub will provide the public website address.

## Before publishing
Edit `index.html`:
- Replace the placeholder phone number.
- Replace `https://calendar.google.com/` with the Google Calendar sharing/public calendar link.
- Replace the offering/purpose paragraph if desired.

Add two photos:
- `images/cottage-1.jpg`
- `images/cottage-2.jpg`

The site is intentionally plain HTML/CSS so it has no paid software, database, plugin, or maintenance dependency.
